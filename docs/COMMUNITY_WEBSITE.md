# 网页社区与桌面入口

网页版负责发现、收藏、上传发布和账号资料；桌面版负责本地项目、导出、导入与执行。
桌面点击“社区”会打开网页，当前工作页面保留。旧社区深链显示兼容入口。

## 尚未部署时

开发模式默认打开 `http://127.0.0.1:5174`。正式构建不会使用这个开发缺省地址；
如果未配置域名，软件显示“尚未配置社区网站”，不会跳到客户电脑上的本地端口。

有域名后，在构建桌面前设置公开网站基础地址：

```sh
cd web
VITE_COMMUNITY_SITE_URL=https://你的社区域名 npm run build --workspace @veyra/desktop
```

此项是公开地址，不填写账号、密钥、查询参数或页面锚点。路径和语言由客户端组合。
Tauri 使用现有 shell 插件的 HTTP(S) 打开能力；不能打开文件、命令、mailto 或 tel。
真实安装包外开行为仍须在重新构建后验收，静态检查不能代替安装包运行证据。

## 上传与下载

1. 在桌面 Studio 等待自动保存完成，导出 Agent 定义文件。
2. 网页登录后进入“我的”，选择 Agent 或 Plugin Pack，选择导出文件。
3. 先在浏览器本地检查文件名、大小、摘要及可读内容。选择文件本身不上传。
4. 勾选确认后才发送这个精确文件快照。服务器继续检查格式、敏感内容与审核状态。
5. 已发布、审核中和被拒绝的 Agent / Plugin 版本均可从个人记录查看。

当前上传格式为 Agent `.vagent.yaml`（上限1,000,000字节）和 Plugin Pack
`.vplugin.zip`（上限5,000,000字节）。Workflow、Project、Template 的网页分享契约
尚未接通，发布中心如实显示不可用，不把它们作为 Agent 文件上传。

下载 Agent 后，在桌面项目 Agent 分组的“+ → 导入 Agent 文件”中导入；下载不会
自动执行。Plugin Pack 需在桌面资源目录导入并经过既有检查/启用流程。
网页不会同步本地 Project、Run、聊天或凭据，也不执行上传的定义。

## 个人记录接口与账号绑定

`GET /api/v1/registry/mine/plugins` 只返回认证用户自己的插件全部版本/状态；
旧服务没有该接口会返回404，需加载当前后端代码。
新网页上传携带 `expected_publisher_id`。Agent/Plugin POST 在认证、CSRF之后核对
实际会话身份，不符返回409，不发布版本。预览按账号隔离，旧列表响应不能覆盖
刚确认的发布回执。
