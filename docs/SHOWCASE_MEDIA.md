# Gift-packaging walkthrough

The 40-second walkthrough shows a recorded Veyra gift-packaging case. It
follows the brief and product photo through the Workflow canvas and form,
then compares the original photo with an existing generated image candidate.
[Watch the walkthrough](../web/apps/community/public/showcase/veyra-gift-tour.mp4)

The parent Workflow run failed. An image task produced a candidate, and the
result still needs review against the design and production requirements.
The file-approval example on the website illustrates the interaction
separately from the recorded run.

The [showcase files](../web/apps/community/public/showcase/) include the
video, screenshots, and Chinese and English captions.
