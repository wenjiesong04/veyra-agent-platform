## 设计方向

在这张页面上，Veyra 已经交付的对账案例成为完整产品故事，而不是用抽象图标
代替工作室。主线是描述方法、检查结构、运行交付、查看依据、决定关键操作。

参考 [Apple 产品展示](https://www.apple.com/macbook-pro/) 的产品优先构图、
[OpenAI](https://openai.com/) 的现代内容层级与
[Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)。
沿用此前指定的 design-taste-frontend / web-design-guidelines 指导，但不复制
第三方产品、商标画面或功能宣称。当前仅有缓存 skill 文档，没有运行其自带的
draw/inspect 脚本；实际浏览器检查使用 CUA，不能称该 inspector 已通过。

页面采用中性白色开场、炭黑产品展台、白色编辑区、浅灰结果区、浅绿控制区和
深色开始使用区。青绿色仅用于关键动作与少量强调。没有渐变、光球、伪数据、
六宫格功能卡或下载空壳。标题使用固定字号与响应式断点，不随视口连续缩放。

## 页面内容与交互

- 首屏以 Veyra 品牌和真实产品图为主，主动作进入产品体验。
- 产品体验可以切换 Builder、Studio、真实交付三个场景，支持方向键、Home/End。
- 编辑区与结果区分别说明可修改的方法、明确版本和可核对依据，不要求访客
  先学习 Source、Draft、Runtime 等内部术语。
- 图片使用原生模态查看器；手机保留大图平移，也能打开原始图片。Escape 关闭
  并恢复焦点。页面不劫持滚动。
- 文件审批是单独标注的交互示例，可以批准、拒绝、重置，焦点跟随状态。
  它不读写文件、不调用模型，也不伪装为对账案例的真实写入记录。
- 文档、源码和构建指南为真实链接；公开安装包未通过验收，不设置下载按钮。
- 中英文、明暗主题和减少动态效果复用现有 `@veyra/ui` 偏好，不再另建原型偏好键。
- 动效以 CSS 位移和场景切换为主，系统 reduced-motion 下禁用动画与过渡；无 GSAP
  或新依赖。浏览器本轮未模拟系统 reduced-motion，规则存在不冒称分支已实测。
